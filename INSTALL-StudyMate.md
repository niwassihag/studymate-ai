# StudyMate AI 3.0 - Testbook capture

Install StudyMate-AI.apk over the previous app. Export a backup first. Do not uninstall the old version unless you have a backup. If Android prompts, allow installation from the browser/file manager used to download it.

Open Platforms > Testbook. Sign in on Testbook's own page, then open an attempted test > Analysis. Supported score and accuracy fields are captured after loading; StudyMate returns to your results and updates the planner. No screenshot, upload or typing scores needed. Use the floating StudyMate button or Android Back to return without capture. If Google login opens externally, use the site's phone/email login.

Reopening the same attempt updates its record without duplicates. The date is the import date because the inspected result page did not expose the original attempt date. Available sections below 70% accuracy become focus areas. Missing topic-level data is not invented.

This is experimental page-based capture, not an official Testbook integration. It only works for supported Analysis pages opened inside StudyMate. A test taken in another app does not sync in the background: open its Analysis inside StudyMate. Website changes, unsupported result layouts or login restrictions may interrupt capture. Oliveboard and custom platforms remain manual. The PWA cannot capture other websites.

Internet permission is used for Testbook. Records and the planner remain local. Testbook handles login/session storage. StudyMate does not request your password separately. Backups contain study records, not login cookies. Clearing app data or uninstalling removes local records and sessions.

Requires Android 6.0+ and a current Android System WebView. Signature, package integrity, manifest/resources and bytecode structure passed checks. Tests passed for the observed score format, duplicate prevention, invalid data rejection and app save callback. No Android phone or emulator was available: installation, login and end-to-end capture on Android remain unverified.
